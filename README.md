# 极简天气 🌤️

一款纯前端天气查询应用，支持实时天气查询、天气预报、天气预警等功能。

## ✨ 功能特性

### 🌡️ 天气查询
- **实时天气**：获取当前天气状况（温度、湿度、风速、气压、能见度）
- **24小时预报**：3小时天气变化趋势
- **未来5天预报**：每日天气概况
- **空气质量**：实时AQI指数和空气质量等级

### 🔔 天气预警
- **实时预警**：获取当前城市的天气预警信息
- **智能过滤**：只显示当前城市的预警
- **多种类型**：支持雷电、大风、暴雨、暴雪、高温、寒潮等预警类型
- **分级显示**：红色/橙色/黄色/蓝色四级预警

### 🏙️ 城市管理
- **中文搜索**：支持中文城市名搜索，智能提示
- **城市收藏**：收藏常用城市，快速切换
- **默认城市**：设置默认显示城市

### 🔗 社交分享
- **多平台分享**：支持微博、QQ分享
- **生成图片**：一键生成天气卡片图片下载

### 🎨 主题切换
- **日间模式**：清新明亮的浅色主题
- **夜间模式**：护眼舒适的深色主题

### 📱 响应式设计
- 完美适配PC端和移动端

## 🚀 技术栈

- **前端框架**: HTML5 + CSS3 + JavaScript ES6+
- **布局方案**: Flexbox + CSS Grid
- **样式特性**: CSS变量、动画效果、响应式设计
- **数据存储**: LocalStorage
- **天气API**: OpenWeatherMap + APISpace预警API

2. **APISpace** - 天气预警数据

## 🎯 使用说明

### 搜索城市

1. 在搜索框中输入中文城市名（如：北京、上海、广州）
2. 点击搜索按钮或按回车键进行查询
3. 支持搜索建议自动补全

### 查看预警

预警信息会自动显示在城市名称下方：
- 如果当前城市有天气预警，会显示预警卡片
- 如果没有预警，则不显示预警区域

### 收藏城市

1. 点击城市名称旁边的心形按钮
2. 收藏的城市会显示在收藏列表中
3. 支持设置默认城市

### 分享天气

1. 点击分享按钮打开分享菜单
2. 选择分享平台或复制链接
3. 支持生成天气卡片图片下载

### 主题切换

点击右上角的月亮/太阳图标切换日间/夜间模式。
